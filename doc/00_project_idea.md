# 00 — Project Idea

## Проблема

Разработчики на Python ежедневно ищут ответы на Stack Overflow, но поиск по ключевым словам часто возвращает нерелевантные результаты — особенно для вопросов, сформулированных своими словами. Нет инструмента, который позволяет задать вопрос на естественном языке и получить точный ответ именно из проверенной базы SO, со ссылкой на источник.

## Цель проекта

Построить RAG-систему, которая:
1. Индексирует реальные вопросы и принятые ответы Stack Overflow по Python.
2. Принимает вопрос пользователя на естественном языке.
3. Находит релевантные фрагменты и генерирует ответ **только** из них.
4. Честно отказывает, если релевантных данных нет.

## Для кого проект

- Студенты и джуниор-разработчики, изучающие Python.
- Опытные разработчики, которым нужен быстрый справочник по синтаксису/паттернам.

## Данные

| Параметр | Значение |
|---|---|
| Источник | [stackoverflow/stacksample](https://www.kaggle.com/datasets/stackoverflow/stacksample) на Kaggle |
| Формат | CSV (Questions.csv, Answers.csv, Tags.csv) |
| Масштаб | 10% всех вопросов SO → ~1 млн записей в сырых данных |
| После фильтрации | ≥ 1 000 Python-вопросов с принятым ответом и score ≥ 5 |
| Лицензия | CC BY-SA 3.0 |

## Критерий успеха

- Pipeline запускается командой `uv run python scripts/build_index.py` без ошибок.
- На 3 демо-вопроса по Python приходит осмысленный ответ с источником.
- На вопрос про торт ("chocolate cake recipe") система возвращает явный отказ.
- Все тесты (`uv run pytest tests/ -v`) зелёные.
